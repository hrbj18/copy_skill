# 单次开发指导文档：先补全证据的前二十科技热榜

日期：2026-09-02  
状态：冻结，实施中  
工作目录：`D:\work\copy_skill`

## 目标

把面向人的 `每日科技热点榜.md` 从“官方来源事件的五条摘要”改为“昨日抖音科技热点前二十”。榜单必须严格按既有 `heat_rank` 排序；每条先由多段可审计的内容证据补全出主体、动作、对象和关键变化，再由中文写作模型生成读者一眼能懂的标题与一至两句简述。

## 已验证问题

- 当前 2026-09-01 包有 33 条候选，但前二十中仅 4 条是 `news_ready`，且只有 9 条已有主体、动作、对象三槽完整。
- 许多原始标题是视频钩子或情绪句，例如“库克正式退位”“4GB 显存跑 70B”，不能直接当新闻标题，也不能由模型凭空补全。
- 因此只改 Markdown 不能解决问题；必须先增加每个热点的内容证据覆盖与结构化事实卡。

## 冻结设计

1. 保留候选池的原始热度、`heat_rank`、`delivery_rank`、真实性状态与排序公式；事实补全、模型输出和人类写作均不得参与排序。
2. 从热度前二十事件开始，为每项聚合最多三段来自不同贡献视频的原始平台文字、截图文字或已有内容证据。单个视频标题不再是唯一输入。
3. 对内容不足的前二十代表视频，在既有受限下载和截图文字预算内优先补充画面文字；不为此启动音频识别。所有提取文字与选择理由保留在机器合同。
4. 第一轮模型只把证据整理为受支持的事件事实卡。卡片必须能说明主体、动作、对象和关键变化，数字不得超出输入。证据不足的事件标为 `insufficient`，不得伪造为完整新闻。
5. 第二轮模型只接收合格事实卡，按 `human-writing` 的短新闻要求生成 `consumer_title` 和 `consumer_summary`。标题优先写“谁做了什么”，摘要补充读者最关心的变化；不含来源、原话、URL、热度、真实性标签、模型话术或套话。
6. 人类榜单仅渲染前二十中合格的消费卡，并按 `heat_rank` 升序。若合格数少于二十，包必须诚实标为 `partial` 并写明缺口；绝不能为了凑数回退为钩子标题或虚构详情。
7. `official-discovery.json` 保持独立的来源优先通道和审计职责，不再决定人类热榜的行数或排序。

## 实施任务

1. 扩展故事内容补全器，支持多贡献视频证据聚合、前二十截图文字补全和可审计的证据覆盖统计。
2. 新增确定性事实卡校验和受限的批量事实整理模型调用，拒绝主体、动作或对象缺失及新增数字。
3. 新增独立的消费端卡片写作批次，使用结构化事实卡而非原始视频标题；把输出和回退原因写入 `candidate-pool.json`、`run-report.json`。
4. 改写 `每日科技热点榜.md` 渲染器，输出按热度的至多二十条简洁中文新闻卡，不泄露审计字段。
5. 补充测试，覆盖多证据选择、事实卡字段与数字校验、二十条热度顺序、未达二十时的真实降级，以及官方事件和候选热榜的隔离。

## 预算与安全边界

- 不读取 `.env.local`、Cookie 或浏览器档案；不改 OpenMontage、调度器和 `third_party/MediaCrawler`。
- 截图文字只处理热度前二十的代表视频，最多二十个视频，单视频和总时限均由配置约束；音频处理保持禁用。
- 两轮模型调用均分批、有输出长度上限、受全局一小时任务预算约束。模型只可压缩输入证据，不能联网、核真或补充外部事实。
- Douyin 仍仅是热点与内容线索，不构成事实证明；机器合同保留 `truth_status: not_checked` 和缺口。

## 验收标准

1. 具备至少二十个合格消费卡时，`每日科技热点榜.md` 恰有二十条，顺序与候选 `heat_rank` 一致；无热度数值、链接、来源、日期、原话或模型说明。
2. 每条消费卡的标题清楚说出主体和动作，摘要说清对象或关键变化；标题不复用原始钩子式标题。
3. 每条已渲染卡在机器合同内都能追溯到多段或经截图补全的内容证据、事实卡和写作状态；模型不得新增输入中不存在的数字。
4. 证据不足时不会以原始标题凑足二十条，结果如实为 `partial`，报告包含可量化的缺口。
5. `heat_score`、`heat_rank`、`delivery_priority_score`、`delivery_rank`、`truth_status` 和官方事件隔离不变。
6. 聚焦测试、全量 pytest、compileall、CLI help、doctor、真实运行、pack inspect 和 handoff audit 通过；浏览器页面和租约归零。

## 完成定义

只有当新的前二十证据链、事实卡、人类短新闻榜单与机器审计明确分工，并通过真实运行和上述验证，才标记本任务完成。
