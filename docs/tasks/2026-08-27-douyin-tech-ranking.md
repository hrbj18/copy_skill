# 抖音科技新闻排行榜

日期：2026-08-27  
状态：当前任务

## 目标

交付一个由受限抖音公开元数据发现和排名、由官方/第一方 HTTPS 新闻源核验事实的“抖音科技新闻排行榜”。排行榜不是官方 RSS 列表，也不依赖 LLM；HTTP 模型调用继续关闭。

## 范围与决定

- 抖音只提供标题、发布时间、作者、普通分享链接及公开互动计数，作为热点发现、聚类和排名信号；不得用其证明新闻事实。
- 通过项目拥有的 MediaCrawler 适配器，以有限科技关键词、并发 1、全局最多 10 条去重元数据采集。页面多返回时本地截断，不追加请求；不下载媒体。
- 相同主题聚类后使用固定、确定性热度公式：经对数压缩的点赞、评论、收藏、分享分，加相关视频数量分和发布时间衰减。公式、权重、输入分项和稳定排序证据写入代码/配置和报告；LLM 不得决定名次。
- 按标题、实体、关键词及目标日窗口匹配官方 HTTPS 新闻记录。已满足来源门槛的进入已核验榜；仅有抖音线索的严格进入待核验候选区。
- 每个榜项必须显示排名、总分与分项、视频数、热度窗口、互动/聚类驱动的热度原因、官方核验摘要、官方日期/链接、普通分享链接、核验状态和内容角度。无 HTTPS LLM 时明确使用确定性模板且 AI 深度分析不可用。
- 工作台新增“生成抖音科技热榜”，调用独立正式路径：Douyin metadata → 聚类/评分 → 官方核验 → `output/douyin-tech-ranking/<target-date>/ranking.{md,json}`，显示有限进度、数量、报告路径和简短错误；不依赖 Voicebox。

## 明确排除与安全边界

- 不安装、启用或运行 `CopySkillDailyTechNews`；只允许最终只读查询。
- 不读取 `.env.local`、Cookie 或浏览器认证资料；不输出 API Key、Cookie、签名媒体 URL 或浏览器认证信息。
- 不修改 `third_party/MediaCrawler`、不写入 `D:\codex_work\OpenMontage`。所有网络和子进程使用有限超时；遇登录、二维码或 CAPTCHA 立即停止外部采集步骤。
- 不因 HTTPS LLM 端点缺失而阻塞基础排行。抖音无数据、登录要求或新闻源失败时，以严格分区、空结果或降级报告如实呈现。

## 交付与验收

- 项目拥有的采集适配、聚类、评分、官方核验、JSON/Markdown 报告及工作台入口。
- 单元/集成测试覆盖公式确定性、衰减、极端值、聚类、稳定排序、核验分区、10 条预算、敏感字段移除、无数据/登录/来源失败降级及工作台命令路径。
- 首次涉采集或子进程的聚焦和完整 pytest 在独立 Windows 进程组、有限超时运行。
- 完成一次真实、受限、无媒体下载的工作台同路径运行；若要求登录则立即暂停该外部步骤，继续离线测试。
- 执行完整回归、输出敏感扫描、handoff 更新、仅追加过程记录与只读 scheduler query。

## 通过条件

只有真实排名来自抖音公开互动和时间信号、新闻事实来自可靠 HTTPS 来源核验、并且工作台可手动生成严格分区的榜单时，功能才算完成。普通官方新闻列表不构成通过。
