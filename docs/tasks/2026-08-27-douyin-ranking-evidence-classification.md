# 抖音科技热点榜证据分类修正

日期：2026-08-27  
状态：当前任务

## 目标

将抖音科技榜从“官方新闻是否匹配决定是否采纳”修正为统一的抖音热点总榜。热度资格、事实可信度和创作参考价值互不混淆：所有元数据完整且有热度的主题进入主榜；官方来源只限制外部事实的表述与证据标签。

## 分类契约

- `verified_news`：外部科技事件具有官方/可靠 HTTPS 来源核验。可陈述为已核验新闻，并列出链接。
- `creator_original`：博主原创评测、实验、演示、教程、观点或创意。普通抖音分享链接、作者和发布时间是“作者发布了该内容”的一手参考；不得把视频中未核验的产品规格或公司行为写成外部事实。
- `unverified_claim`：涉及新品发布、规格、公司行为等外部事实性主张但尚无可靠来源。仍可入热榜，但必须标记未核实主张/传闻。

## 范围与决定

- 排名只由现有确定性抖音热度分决定，官方来源不得改变名次；另外显示事实可信度和创作参考价值。
- Markdown/JSON 依次包含统一总榜、已核验新闻、博主原创内容、未核实事实主张；口播采用对应类型措辞。
- 优先复用 `output/douyin-tech-ranking/2026-08-26` 的安全元数据与报告证据，不发起新的抖音采集。
- 将本次扫地机主题判为原创评测/观点，Mac Studio 本地 AI 讨论判为原创实验/观点，M6 Mac mini 说法判为未核实产品主张，除非存在可靠苹果官方来源。

## 安全与验收

- 不安装、启用或运行计划任务；不读取 `.env.local`、Cookie 或认证资料；不下载媒体。
- 测试原创无外部新闻仍入主榜、未核实主张警告、官方来源不影响热度排序、普通抖音链接保留和事实措辞边界。
- 运行聚焦测试、独立 Windows 进程组完整回归和敏感输出扫描；更新产品规则、handoff，并仅追加过程记录。
