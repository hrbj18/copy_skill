## 2. 冻结方案

1. `github` 等平台/生态词不能作为具体产品锚点。
2. `deepseek`、`codex` 等公司或宽产品生态词只能提供相关话题信号；只有具体模型、版本、项目名、强文本相似或其他明确锚点才能合并为同一事件。
3. 继续保留 Hy4、V27、OpenClaw 2.0 等具体产品/版本锚点的同事件合并能力。
4. ASCII 游戏词按完整词边界匹配；`SwitchTool` 不得因包含 `switch` 字符串被判为游戏。
5. 游戏范围门以代表标题和原始贡献标题的多数一致性判断“纯游戏”。某个综合盘点只在局部提到游戏，不能排除整个科技事件。
6. 纯游戏单视频或多数贡献视频明确属于新游、评测、攻略、试玩、Steam/Switch/主机内容时仍须排除。
7. 不读取 LLM 摘要、OCR 文本、图片或事实状态参与聚类和范围判断。
