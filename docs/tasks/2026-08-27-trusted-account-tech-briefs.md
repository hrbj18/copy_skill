## 冻结目标与产品决策

- 本次只交付“固定可信科技新闻账号 → 北京时间近 48 小时作品 → 安全文本/必要时本地转写 → 内容提炼或确定性降级 → 单账号公开互动热度排行 → 工作台与报告”。暂停扩大关键词热榜。
- 首个账号入口固定为 `https://v.douyin.com/PoAPJ56GPu0/`。安全解析稳定账号 ID、主页、作者名；粉丝数仅在页面可观察时记录，否则为 `null`。
- 可信等级由配置或用户人工批准：`trusted_creator` / `high` / `user_curated_account`。它允许跳过逐条官方淘汰，但绝不等同于 `verified_official`；事实措辞必须是“据财研网AI本条视频介绍/依据其字幕整理”。
- 排名仅由单账号窗口内可用点赞、评论、收藏、分享和时间衰减决定；缺失互动保持 `null/unavailable`，不得伪装成 0，LLM 和可信等级不影响名次。

## 范围、资源和安全边界

- 窗口为运行开始时向前 48 小时，`Asia/Shanghai`；只处理目标账号且最多 10 条，并发 1，上游多返回时本地过滤/截断，不追加请求。
- 字幕优先级：平台字幕 → 标题/描述 → 必要时项目现有临时媒体与本地 CPU ASR → 可选受限 OCR。单条失败降级，长期仅保存安全字幕与结构化数据。
- 临时媒体仅限该账号、本窗口、10 条以内；下载/大小/转写/总任务均有限预算，成功或失败后清理，不保存签名 URL、Cookie、认证资料或浏览器配置。
- 登录、二维码、CAPTCHA 立即停止外部步骤并进入可操作状态；禁止绕过或高频重试。
- 模型仅允许证书校验正常的 HTTPS OpenAI-compatible 端点。不得读取或显示 `.env.local`、API Key、Cookie；不得恢复明文 HTTP、跳过证书校验或套本地 TLS。无安全端点时输出 `disabled_missing_https_endpoint` 和确定性摘要，不冒充模型结果。
- 不依赖 Voicebox，不修改 `third_party/MediaCrawler`，不写 OpenMontage，不安装、启用或运行 Windows 计划任务。
